# NexOS - 纯 x86 汇编操作系统

## 项目概述
NexOS 是一个完全用 x86 汇编语言编写的独立操作系统，目标是打造类似 Windows 的图形化操作系统。当前版本已实现核心引导链、图形桌面、窗口管理器和基础驱动。

## 已实现功能

### 引导链 (Boot Chain)
- **boot.asm** (512字节引导扇区): CHS方式读取stage2到0x0800，传递启动驱动器号
- **stage2.asm** (8KB第二阶段): 
  - VBE 图形模式设置 (800x600x32bpp)
  - PCI BAR0 编程启用线性帧缓冲 (0xE0000000)
  - 读取内核到内存，进入32位保护模式
  - 复制内核到 0x100000 并跳转

### 内核 (Kernel)
- **kernel.asm**: 主函数，初始化所有子系统，主循环重绘桌面
- **idt.asm**: IDT + PIC 8259 初始化，IRQ0(定时器)/IRQ1(键盘)/IRQ12(鼠标)中断存根
- **boot.asm**: 内核入口，设置栈，调用 kernel_main

### 驱动 (Drivers)
- **vga.asm**: VBE 帧缓冲驱动
  - 支持 24bpp / 32bpp
  - fill_rect (填充矩形)
  - put_pixel (画点)
  - draw_char_fast (8x16 字体)
  - draw_string (画字符串)
  - clear_screen (清屏)
- **keyboard.asm**: PS/2 键盘驱动，扫描码转换，Shift/Caps Lock 支持，环形缓冲区
- **mouse.asm**: PS/2 鼠标驱动，3字节数据包解析，坐标边界检查，光标绘制

### 用户界面 (UI)
- **desktop.asm**: 窗口管理器
  - 桌面背景 (深蓝色 0x1a1a2e)
  - 窗口创建/绘制 (主体、标题栏、边框、关闭按钮)
  - 窗口拖拽支持
  - 任务栏 (底部 40px)
  - 开始按钮

## 文件扩展名设计 (规划)
| 扩展名 | 类型 | 说明 |
|--------|------|------|
| .nx | 可执行文件 | NexOS 原生可执行格式 |
| .nxl | 库文件 | 动态/静态链接库 |
| .nxf | 磁盘镜像 | NexOS 文件系统镜像 |
| .nxpkg | 软件包 | 可安装软件包格式 |
| .nxcfg | 配置文件 | 系统/应用配置 |
| .nxt | 文本文件 | 纯文本格式 |
| .nxv | 矢量图 | 矢量图形格式 |
| .nxa | 音频 | 音频格式 |
| .nxm | 视频 | 视频格式 |

## 文件系统 (规划)
- **NXFS**: 自研文件系统，支持大文件、权限、日志
- 与 Windows 磁盘互通，Windows 端需安装 NexOS 文件系统驱动

## 软件包管理 (规划)
- **.nxpkg** 格式：压缩包 + 元数据 + 安装脚本
- **nxpkgmgr**: 软件包管理器，支持安装/卸载/更新/依赖解决

## 容量规划 (目标)
- 安装包：52GB+
- 安装后占用：106GB+
- 预置大量软件（办公、开发、娱乐、工具等）

## 文件结构
```
NexOS/
├── boot/
│   ├── boot.asm          # 引导扇区 (512字节)
│   └── stage2.asm        # 第二阶段引导 (8KB)
├── kernel/
│   ├── boot.asm          # 内核入口
│   ├── kernel.asm        # 内核主函数
│   └── idt.asm           # 中断描述符表
├── drivers/
│   ├── vga.asm           # VBE 帧缓冲驱动
│   ├── keyboard.asm      # PS/2 键盘驱动
│   └── mouse.asm         # PS/2 鼠标驱动
├── ui/
│   └── desktop.asm       # 窗口管理器/桌面
├── linker.ld             # 链接脚本
├── Makefile              # 构建脚本
└── build/
    ├── NexOS.img         # 可引导软盘镜像 (1.44MB)
    └── kernel.bin        # 内核二进制
```

## 构建方法
```bash
make all
```
依赖：nasm, ld, qemu-system-x86

## 运行方法
```bash
qemu-system-i386 -fda build/NexOS.img -m 256 -vga std -boot a
```

## 技术要点
1. **纯汇编实现**: 全部代码使用 NASM x86 汇编，无 C 代码
2. **自研引导链**: 不依赖 GRUB，从引导扇区到内核完全自主
3. **VBE 线性帧缓冲**: 通过 PCI BAR0 编程启用 0xE0000000 线性帧缓冲
4. **32位保护模式**: 内核运行在 32 位保护模式，平坦内存模型
5. **中断驱动**: IDT + PIC，支持键盘/鼠标/定时器中断
